Title: Gradebook project
Author: Stella Oshana
This project allows students to keep track of their grades in different subjects. Users can add and remove grades, calculate class averages, check their overall GPA, and see a visual representation of their grades. 
The gradebook.py and csv files are the two I used. The gradebook.py file contains the main Python code that allows users to add, remove, view and calculate grades. as well as check their GPA and visualize their averages. The csv file stores the subjects and their grades so the data can be saved and loaded when the program runs again.
